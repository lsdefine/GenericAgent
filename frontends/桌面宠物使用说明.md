# 桌面宠物系统 - 完整说明

## ✅ 已完成的改进

### 1. 优雅的多皮肤架构
- **8 种像素风桌宠**：boy, dinosaur, doux, glube, line, mort, tard, vita
- **即插即用**：只需将皮肤文件夹放入 `skins/` 目录
- **自动发现**：无需手动注册，启动时自动扫描
- **右键切换**：运行时可随时切换皮肤

### 2. 多动画状态支持
- **idle** - 待机状态
- **walk** - 行走状态  
- **run** - 跑步状态
- **sprint** - 冲刺状态

### 3. 完整的 GA 集成
- ✅ 从 stapp.py 点击"🐱 桌面宠物"按钮启动
- ✅ 每个 turn 结束时自动发送通知
- ✅ HTTP 接口支持消息和状态控制
- ✅ 跨平台支持（macOS/Windows/Linux）

## 使用方法

### 方式1：从 GA 启动（推荐）
1. 运行 `streamlit run frontends/stapp.py`
2. 点击侧边栏的"🐱 桌面宠物"按钮
3. 桌宠会自动启动，并在每个 turn 结束时显示通知

### 方式2：独立运行
```bash
python3 frontends/desktop_pet_v2.pyw
```

## 交互方式

- **单击拖动** - 移动桌宠位置
- **双击** - 关闭桌宠
- **右键菜单**：
  - Animation - 切换动画状态
  - Switch Skin - 切换皮肤
  - Exit - 退出

## HTTP 远程控制

```bash
# 显示消息（支持中文）
curl "http://127.0.0.1:51983/?msg=任务完成"

# 切换动画状态
curl "http://127.0.0.1:51983/?state=run"

# POST 方式发送消息
curl -X POST -d "Hello" http://127.0.0.1:51983/
```

## 添加新皮肤

### 步骤1：准备皮肤文件
```
frontends/skins/
└── my-pet/
    ├── skin.json       # 配置文件
    ├── idle.png        # 待机动画
    ├── walk.png        # 行走动画
    ├── run.png         # 跑步动画
    └── sprint.png      # 冲刺动画
```

### 步骤2：编写 skin.json
```json
{
  "name": "My Pet",
  "version": "1.0.0",
  "author": "Your Name",
  "description": "我的桌宠",
  "format": "sprite",
  "animations": {
    "idle": {
      "file": "idle.png",
      "loop": true,
      "sprite": {
        "frameWidth": 44,
        "frameHeight": 31,
        "frameCount": 6,
        "columns": 6,
        "fps": 6,
        "startFrame": 0
      }
    }
  }
}
```

### 步骤3：重启桌宠
新皮肤会自动出现在右键菜单中。

## 从 ai-bubu 导入更多皮肤

## 技术细节

### 架构设计
- **SkinLoader** - 皮肤配置加载
- **AnimationLoader** - 动画帧加载（支持 sprite sheet 和 GIF）
- **Pet** - 主窗口和交互逻辑
- **HTTP Server** - 远程控制接口

### 跨平台兼容
- macOS: 使用 `-transparent` 和 `systemTransparent`
- Windows: 使用 `-transparentcolor` 色键
- Linux: 自动降级到白色背景

### 性能优化
- PIL/Pillow 高效加载图片
- ImageTk 转换确保兼容性
- 帧缓存避免重复加载

## 故障排查

### 桌宠无法启动
```bash
# 检查依赖
pip install pillow

# 测试启动
python3 frontends/desktop_pet_v2.pyw
```

### 皮肤不显示
1. 检查 `skin.json` 格式
2. 确认图片文件存在
3. 验证 sprite 配置参数

### HTTP 接口无响应
```bash
# 检查端口占用
lsof -i :51983

# 测试连接
curl http://127.0.0.1:51983/?msg=test
```
