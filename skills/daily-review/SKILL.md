# daily-review Skill — 每日结构化复盘

## 背景

einvest系统是一套高度工程化的量化复盘工具，核心理念：「复盘不是预测明天涨跌，而是定位自己在哪、验证策略对不对、修正信号」。

einvest实盘报告（2026/06/25）展示了其完整形态：Dashboard带历史同态胜率（每行指标含1d/5d/20d胜率+赔率+权重点）、板块周期精确到子板块（CHIPLET/光刻机/存储芯片）并追踪连涨股数、投机情绪系统（涨停/跌停/炸板/连板统计+7策略路由）、量化筹码池（高换手+量能暴增筛选）。

本Skill将einvest框架映射到市镜Next数据体系，保留其结构化复盘基因，用我们自己的数据源生成每日复盘报告。

## 收到 einvest PDF 报告的标准动作

当用户发送文件名含"einvest复盘系统"的PDF时，自动执行以下流程：

1. **读PDF**：用 pdftotext 提取全文
2. **状态机定位**：提取 Dashboard 中的状态机节点（R1_AFTER/B2/B2_EXIT等）、历史同态胜率、风险评分
3. **板块扫描**：提取 SC30/SC3 排名、板块周期阶段、子板块趋势方向
4. **周期论检查**：提取周期论标签，⚠️ 对照状态机检查是否矛盾（按L118警告执行）
5. **信号验证**：提取"昨日对错"面板、信号状态变化
6. **与上一交易日交叉比对**：如有上一份einvest报告记录，逐项对比变化方向（如 SC3 从 39→24、方向从"瓦解"→"酝酿"等）
7. **一句话总结**：当前处于什么位置、什么该做什么不该做
8. **存入记录**：将关键数据写入 `_GA_outputs/einvest/einvest_record.json` 供下次交叉比对

> 注：这是对einvest原报告的"解读与定位"，不是替代einvest跑复盘。如果用户同时需要市镜Next自己的复盘，用下方 fetch_data.py 生成。

## 数据脚本

`scripts/fetch_data.py` 一次查询拉取所有需要的数据。用法：

```bash
python3 scripts/fetch_data.py --date 2026-06-26 --db /path/to/shijing.db --output /tmp/review_data.json
```

输出的JSON包含这些数据域：
- `mti` — MTI温度历史（最近15条）
- `index_chan` — 指数禅论结构（四大指数stage/phase/signal）
- `index_daily` — 指数日线涨跌（四大指数最新行情）
- `sectors` — fact_sw_industry_daily行业涨跌（全部申万行业，含前一交易日对比）
- `signals` / `prev_signals` — 当日/前日signal_state_daily
- `portfolio` — 虚拟账户当前持仓
- `asset` — 资产快照（最近20条）
- `shadow_ledger` — 影子交易账本（最近1850+条，复盘只看最近10条）
- `price_for_verify` / `held_stock_prices` — 用于T+1信号验证

### 数据结构备忘（分析脚本必读）

**index_daily 是嵌套结构，pct_chg 不在顶层！**
```
index_daily[code] = {
    "name": "上证指数",
    "bars": [
        {"trade_date": "2026-06-22", "open": ..., "high": ..., "low": ..., "close": ..., "pct_chg": 1.78},
        ...
        {"trade_date": "2026-06-26", "open": ..., "high": ..., "low": ..., "close": 4027.26, "pct_chg": -2.26}
    ]
}
```
- 取当日涨跌：`data['index_daily'][code]['bars'][-1]['pct_chg']`
- 取当日收盘：`data['index_daily'][code]['bars'][-1]['close']`
- 取近5日走势：遍历 `bars`
- ❌ 错误写法：`idx_info.get('pct_chg', 0)` — 这是顶层 dict，没有 pct_chg 字段，永远返回0

**held_stock_prices 也是嵌套结构（与 index_daily 不同）**
```
held_stock_prices[code] = {"close": ..., "pct_chg": ...}  # 直接挂在 code 下
```

**price_for_verify 更扁平**
```
price_for_verify[code] = {"close": ..., "pct_chg": ...}
```

**MTI 字段名**
- `calc_date`（不是 `date`）
- `mti_score`（不是 `mti_val`）
- `adv_ratio` / `adv_count` / `dec_count`

**signals / prev_signals 字段名**
- `current_tag`（不是 `signal_state`）
- 可能值：`"必须走"` `"弱势"` `"观察"` `"b段主升持有中"` `"强买"`

**sectors 的 trade_date 不是当日**
- `sectors[].trade_date` 可能是历史日期（如 20251231），不要用作最新日期判断
- 用 `sectors[].pct_chg` 排序板块，用 `prev_pct_chg` 看方向变化

## 六步复盘流程

### 第一步：综合市场状态 Dashboard（30秒）

**目标**：一句话定位当下市场状态 + 风险评分。

**从数据中提取**：

1. **MTI温度与仓位上限**
   - 最新MTI值、所处区间（熊市<0.3 / 震荡0.3-0.6 / 牛市>0.6）
   - 仓位上限（MTI对应：熊市≤10% / 震荡≤20% / 牛市≤30%）
   - MTI趋势方向：对比前5日均值，判断上行/下行/横盘
   - 市场宽度：从MTI的adv_ratio看涨跌比（如28.6%意味着7成个股下跌）

2. **风险评分灯**（市镜Next没有历史同态回测，改用指标自身信号质量）
   - 明日风险：看MTI单日变化幅度 + 指数涨跌幅
   - 短期风险：看MTI 5日趋势 + 指数禅论stage是否转弱
   - 长期风险：看MTI 20日均值方向 + 指数禅论大级别结构
   - 用 🟢黄灯/🔴红灯/🟢绿灯 标注（einvest风格）

3. **指数快照**
   - 上证/深证/创业板/科创50当日涨跌幅
   - 从 index_daily 提取

4. **虚拟账户快照**
   - 总市值/总成本/浮盈浮亏/持仓数

5. **状态路由提示**（einvest中有R1_AFTER/B2等状态路由）
   - 市镜Next没有直接等价，但从MTI+指数禅论可以推导：
   - MTI<0.3 且底背驰 → "熊末初升，可分批试探"
   - 0.3≤MTI<0.6 且上升中枢 → "震荡偏强，仓位上限20%"
   - 0.3≤MTI<0.6 且下降中枢 → "震荡偏弱，仓位上限10%"
   - MTI≥0.6 且上升中枢 → "牛市确立，仓位上限30%"
   - ⚠️ 特殊变体（黄金坑）：上升趋势中SC3急坠至冰点+指数大幅补跌但MTI未破上行趋势 → "高位补跌/黄金坑"（非下行趋势，是上行中的短暂洗盘）→ 找B2点确认，识别穷则变
   - ⚠️ **周期论标签可靠性警告**：einvest的「周期论」模块自动打标（"瓦解早段""酝酿"等）可能滞后或误判。当周期论标签与状态机输出矛盾时，以状态机为准（如6/26状态机输出R1_AFTER但周期论标"瓦解早段"→状态机正确）。复盘时需手动标注此矛盾。
   - 用简短的一句话给出位置判断和操作建议

**输出格式**（对标einvest Dashboard）：
```
📊 综合市场状态：震荡偏强 ★★★★☆
🚦 位置：MTI 0.38（震荡区低位·上升中）| 仓位上限 20%
📈 上证 +0.23% 4120 | 深证 +1.82% 16344 | 创业板 +2.84% 4372 | 科创50 -0.15%
⚠️ 市场宽度：adv_ratio 28.6%（7成个股下跌，指数上涨由权重驱动）
💰 虚拟账户：6只持仓 | 市值 ¥XXX | 浮盈 +3.2%

🔮 风险评分灯：
  明日🟡 46% | 短期🔴 47% | 长期🟢 39%
📐 状态路由：上行初期·低位上升趋势，可分批布局但控制单次仓位
```

### 第二步：指数禅论结构（1分钟）

**目标**：判断大盘趋势结构——这是择时的根。

**从数据中提取**：
- cache_index_chan 中四大指数的 stage、position、phase、signal、outlook
- 四指数是否共振？还是分化？
- 有无背驰信号（top_divergence / bottom_divergence）？
- 注意：cache_index_chan的phase比einvest的"位置灯"更精细（含缠论中枢/背驰判断）

**对照外部观察池**（如有）：
- 博士之路/台球之门等外部观察池的最新周期定位
- 市镜Next的指数禅论对外是否一致
- 如果不一致，标注分歧并降低仓位置信度

**输出格式**：
```
🏗️ 上证：上升中枢·B2_HOLD | 深证：上升中枢·B2_HOLD
   创业板：底背驰·B1_BUY ⚡ | 科创50：横盘·B0_WAIT
共振：上证/深证/创业板三指数共振向上 | 分歧：科创50独立横盘
📐 周期定位：上行初期（R1后确认），与外部观察池一致
```

### 第三步：板块轮动与主线（2分钟）

**目标**：定位主线板块、发现退潮板块、诊断持仓板块。

**从数据中提取**：

1. **行业涨跌榜**（sectors数据）
   - pct_chg前15和后15（注意：sectors有439个申万细分行业）
   - 优先关注一二级行业（避开过于细分的三级子类）
   - 对比prev_pct_chg：哪些在加速？哪些在减速？

2. **多日强势追踪**（einvest的SC30/SC3等价）
   - 从fact_sw_industry_daily计算近3日和近30日累计涨幅
   - 近3日连续正涨幅的板块（短线动量）
   - SC30高位但SC3骤降 → 板块回调预警（背离信号）

3. **主线判断**
   - 连续≥3日位列涨幅榜前20 → 潜在主线
   - 对比einvest报告中的"主线容量/抱团分界"概念：
     - 主线板块内上涨股数占比 > 70% → 主线健康（抱团阶段）
     - 主线板块内上涨股数占比 < 50% → 主线缩容（警惕瓦解）

4. **持仓板块诊断**
   - 每只持仓所属行业当日涨跌
   - 持仓板块是否在主线上？

**5日选板演化表**（对标einvest"最近5日选板详情"）：
```
最近5日选板详情
  T-4         T-3         T-2         T-1         今日
  科技36.6    科技32.8    科技28.9    科技27.6     科技37
  1.科技 2.周期 3.新能源 4.消费 → … → 1.科技37 2.周期33 3.新能源21 4.消费13
  子板块: CHIPLET 80→90   CPO 80→84   存储芯片 78→90
```

**输出格式**（对标einvest板块周期表）：
```
🔥 主线板块（连续3日领涨）：
  科技 56.1（子板块：CHIPLET 94 光刻机 93.9 存储芯片 93.7）
  新能源 37.8 | 周期 35.3

⚠️ 退潮板块：
  消费 15（连续4日走弱）| 化妆品 -2.7% | 教育 -1.7%

🔄 板块背离预警：
  无显著背离（SC30与SC3方向一致）

📋 我的持仓板块：
  医药（华海+0.3%、天坛-0.5%）— 不在当前主线上 ⚠️
  军工电子（海能达+1.2%）— 主线共振 ✅
```

### 第四步：个股信号状态 + 昨日对错验证（3分钟）

**目标**：检验当日信号、验证前日信号准确性——这是einvest最核心的"信号修正闭环"。

**从数据中提取**：
- signals 中 signal_state 分布统计（BUY/SELL/HOLD各多少只）
- 持仓股的当日 signal_state
- 持仓股当日实际涨跌幅（held_stock_prices）

**昨日对错验证**（T+1信号准确性，einvest灵魂设计）：
- 对比 prev_signals 中的信号 vs 今日实际涨跌
- 用 price_for_verify 中的价格计算实际涨跌幅

```
验证逻辑：
prev BUY  → today涨 → ✅ 有效
prev BUY  → today跌 → ❌ 误判（信号需要调整阈值）
prev SELL → today跌 → ✅ 有效
prev SELL → today涨 → ❌ 误判
prev HOLD → any    → — 不评判
```

**信号修正提示**：
- 如果某类信号连续3日准确率 < 50%，标注"⚠️ 信号失效，建议调整阈值"
- 如果持仓股出现信号误判，在Step 5卖出检查中重点标注

**输出格式**：
```
📶 今日信号：BUY 127只 / SELL 218只 / HOLD 4838只
   信号比 BUY/SELL = 0.58（<1.0 = 偏空）

🔍 昨日对错验证（T+1）：
   BUY信号准确率 58%（7/12）— 偏低 ⚠️
   SELL信号准确率 71%（10/14）— 正常

📋 持仓信号：
   海能达：BUY（前日BUY→今日+1.2% ✅ 有效）
   锦浪科技：HOLD（前日BUY→今日-0.8% ❌ 信号误判，关注）
   特发服务：SELL（前日BUY→今日-3.1% ❌ 严重误判，建议核查）
```

### 第五步：影子交易账本 + 卖出检查（2分钟）

**目标**：回顾最近决策 + 按SELL Contract五层框架过一遍每只持仓。

**从数据中提取**：
- shadow_ledger 最近10条交易记录
- 每笔交易的决策理由（如有）和当前持仓状态

**卖出检查**（每只持仓过PR #350 SELL Contract五层）：
1. **L1 价格止损**：是否跌破建仓时记录的止损参考位？
2. **L2 买入理由失效**：板块是否退潮？信号是否还成立？禅论结构是否变坏？
3. **L3 市场宽度恶化**：MTI是否跌破当前仓位阈值？
4. **L4 持仓集中度**：单板块占比是否 > 40%？
5. **L5 止盈纪律**：是否已达到目标收益（如+20%）？

**输出格式**：
```
📒 最近交易（10笔）：
  6/25 BUY 华海药业 @ 医药主线+缠论三买 → 今日微涨，L2买入理由暂成立
  6/25 BUY 大智慧 @ 金融IT+信号BUY → 今日-0.3%

⚡ 卖出检查（5层框架）：
  特发服务：L1 ✅未触发 | L2 ❌板块退潮+信号误判 → 建议减仓观察
  海能达：L1 ✅ | L2 ✅主线共振 | L3 ✅ | L4 ✅ | L5 ✅ → 继续持有
  天坛生物：L1 ✅ | L2 ❌不在主线上 | L3 ✅ → 暂持有，设观察期3天
```

### 第六步：综合判断与明日预案（收盘后/盘前）

**目标**：基于前五步全部信息，给出一句话综合判断 + 明确的操作预案。

**判断项**：
1. 当前处于什么位置（参考einvest的状态路由：上行初期/中期/后期，or下行）
2. 明日适合什么操作（加仓/减仓/持仓不动/观察等待）
3. 仓位安全性评估
4. 买入候选（2-3只，附理由）
5. 卖出候选（明确股票+卖出层级）
6. 明日需要关注的验证信号

**状态路由参考**（借鉴einvest v5状态机 + 四份实盘报告的完整节点，映射到市镜Next可用数据）：

v5状态机节点说明（来自6/14-6/25四份实盘）：
| 节点 | 市场含义 | SC30典型区间 | 操作基调 |
|------|---------|-------------|---------|
| **B2_EXIT** | 大周期下行末端(SC30下穿80)，OR 上行周期中的高位补跌(SC3急坠至冰点但大趋势仍在上行)，冰点区 | <25 | 前者空仓等B1；后者识别黄金坑，跟踪穷则变信号 |
| **B1** | 冰点线刚上穿，上行趋势确立初期 | 25-35 | 可分批左侧布局，等B1+1选大板块 |
| **R1_AFTER** | 上行确认（R1后），趋势延续 | 30-45 | 正常仓位，等B2加仓 |
| **B2** | 加速上行，主线扩散 | 45-70 | 可加仓主线，注意容量 |
| **B2_HOLD** | 高位震荡，主线缩容 | >70 | 减仓非主线，紧止损 |

**穷则变机制**（einvest特色——市场极端点的逆转检测）：
- 触发条件：市场连续下跌后出现「变」族群占比首超「穷」族群 + 低位板块群发逆转 + 跌停收敛
- 协议：T+0仅观察不加仓 → T+1/T+2确认 → 全过后T+3加仓1/3
- 市镜Next等价：MTI底部拐点 + 指数底背驰群发 + 跌停数骤降（需情绪数据）

**简版映射**（无v5状态机数据时用MTI+禅论推导）：
| MTI区间 | 指数禅论 | 等价状态 | 操作 |
|---------|---------|------|------|
| <0.3 | 底背驰 | B2_EXIT→等B1 | 试探性≤10%，跟踪穷则变 |
| 0.3-0.5 | 底背驰确认 | B1 | 分批≤20%，选大板块 |

## 写作风格

- **纯事实，不修饰**：不需要文采。用最直接的方式呈现数据、做出判断。
- **敢下判断，标注置信度**：基于数据给出明确结论，不确定处标注【存疑】。
- **用数字说话**：涨跌比14%比"大部分个股下跌"更准确。
- **结论先行**：每个小节先给结论（一句话），再展开。
- **不编造数据**：数据缺失标注【数据缺失】，不推定。
- **对标einvest简练风格**：einvest的Dashboard一句话就把"R1后6天、SC3=39、空仓等B2、冰点第1天、等第3天再加"全说清楚了。我们也要追求这种信息密度。
